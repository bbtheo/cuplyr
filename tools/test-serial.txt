# Test files that run alone, after the parallel shards have finished, each in
# a fresh R process, one after another (tools/run-tests.R suite). One file name
# per line; '#' starts a comment.
#
# A file belongs here when its result depends on what else runs on the machine
# at the same time: it asserts a wall-clock time, it asserts GPU memory amounts
# or needs gigabytes free (a test that skips for lack of memory would skip
# silently next to the shards), or it reads the memory-resource configuration
# of its own process (the shards run with a smaller pool, see CONTRIBUTING.md).
# It is not a place to hide a file that only passes in a particular order: a
# file that fails in a shard but passes here has a bug to fix or report.
#
# New file that times something against a bound (timing_medians(),
# timing_retry(), a bound on elapsed time), asserts GPU memory amounts, or
# needs >= 1 GB free? Add it here with the reason.

# --- asserts GPU memory amounts, or needs gigabytes free --------------------------
test-memory-regression.R        # GPU memory deltas of verbs; the regression gate for leaks
test-gpu-memory.R               # GPU memory deltas and device-level reads; needs 2 GB free
test-parity-F65-async.R         # GB-sized tables, bytes returned to the device, pool and release threshold
test-F57-round2.R               # the real pool against the card's free memory; reloads the resource
test-parity-F57-pool.R          # pool sizes: the initial reservation and device-level used >= pool
test-parity-78-robust-tests.R   # a 1 GB table and "needs 3 GB free"; scans every test file
test-parity-F58-free.R          # skips below 2 GB free: a skip next to the shards would hide a result
test-parity-F61-group-split-memory.R  # skips below 1.5 GB free
test-parity-50-memory.R         # skips below 1 GB free; memory-bound timings
test-F58-scope.R                # skips below 1 GB free; bounds a call at 1 s
