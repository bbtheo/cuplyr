# Describe a window node's specs as "fn-\>output_col" pairs

Describe a window node's specs as "fn-\>output_col" pairs

## Usage

``` r
describe_window_specs(specs)
```

## Arguments

- specs:

  List of
  [`window_spec()`](https://bbtheo.github.io/cuplyr/reference/window_spec.md)
  structures (`R/window.R`)

## Value

Character scalar
