# Patch Makevars for Colab/cloud: add conda lib and driver to RUNPATH

Patch Makevars for Colab/cloud: add conda lib and driver to RUNPATH

## Usage

``` r
patch_makevars_for_cloud(src_dir, driver_lib)
```

## Arguments

- src_dir:

  Source directory containing src/Makevars.

- driver_lib:

  Real driver library path.
