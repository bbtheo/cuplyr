# An all-NA table of `n` rows with a unified schema (a zero-column input's rows in `bind_rows()`)

An all-NA table of `n` rows with a unified schema (a zero-column input's
rows in
[`bind_rows()`](https://bbtheo.github.io/cuplyr/reference/bind_rows.md))

## Usage

``` r
null_table_for_schema(schema, n)
```

## Arguments

- schema:

  List with `names`, `types` and `factor_levels`

- n:

  Row count
