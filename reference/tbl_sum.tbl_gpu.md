# Summary header of a tbl_gpu (pillar)

dplyr's `tbl_sum()` for a data frame or tibble: `"A tibble"`
(`"A data frame"` for an ungrouped table from a plain `data.frame`) with
the dimensions, plus the groups of a grouped table.

## Usage

``` r
# S3 method for class 'tbl_gpu'
tbl_sum(x, ...)
```

## Arguments

- x:

  A `tbl_gpu`.

- ...:

  Ignored.

## Value

A named character vector.
