# Count the operations pending in an AST tree

Like
[`ast_count()`](https://bbtheo.github.io/cuplyr/reference/ast_count.md),
but source nodes (the data a plan starts from) do not count.

## Usage

``` r
ast_count_ops(node)
```

## Arguments

- node:

  Root AST node (or NULL)

## Value

Integer count
